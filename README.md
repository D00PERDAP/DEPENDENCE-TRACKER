# 💀 НЕ НАТВОРИ ДЕЛОВ — бот v2

Простой Telegram-помощник для взрослых, который помогает **отложить импульсивное решение**, напомнить о собственных ограничениях и быстро найти информацию при ухудшении самочувствия. Это не медицинский сервис, не трекер дозировок и не инструкция по употреблению.

## Что изменилось в v2

**В главном меню:**
- **▶️ Начать сопровождение:** 2 шага — вещество и частота. Старый чек-лист сохраняется и редактируется отдельно.
- **☑️ Я НЕ ХОЧУ:** отмечай рискованные поступки. Существующие записи сохранены.
- **🫀 Как я?:** быстрые ответы «нормально», «тревога», «тянет натворить», «не сплю», «физически плохо».
- **🔥 Останови меня:** отдельные действия при желании продолжить, звонить людям/бывшей, тратить деньги, куда-то ехать, бессоннице и паранойе. Можно включить **10-минутную проверку**, только по нажатию пользователя.
- **🆘 Мне плохо / ❓ Вопросы:** вещество → симптом → конкретная краткая карточка. При боли в груди, нарушении дыхания, судорогах, выраженном перегреве, потере сознания — сразу рекомендация вызвать местную экстренную помощь; **никаких мемов вместо срочной помощи**.
- **☀️ После сессии:** короткий опрос; по желанию можно назначить проверку состояния через 8 часов. Никакой автоматической ночной рассылки без согласия.
- **🔔 Напоминания:** каждые **10 / 15 / 30 / 60 минут** на выбор, усиление до 10 минут на час, возможность полностью отключить. В напоминаниях — собственные запреты и конкретный совет по актуальному риску; если есть действительно подходящий одобренный мем, приходит изображение.
- **📊 Статистика:** приватный JPEG-график за месяц: дни с отметками, вещества, проблемные импульсы, проверка состояния и отметки «передумал». Учитывает только самостоятельные записи, **не измеряет фактическое употребление и не ставит диагноз**.
- **🎭 Мем:** в первую очередь реальное фото по тегам **вещество + ситуация**, вместо старых шаблонных карточек. Если тематической картинки нет, бот присылает короткую текстовую шутку, а не случайное изображение. Изображения третьих лиц публикуются только с подтверждённым разрешением.

## Мемы в стиле старых пабликов

Старые автоматические цитатные картинки **отключены по умолчанию** через MEME_LEGACY_CARDS=0. Уже созданные старые файлы не удаляются, но v2 не выбирает файлы, начинающиеся с original_.

Чтобы быстро наполнить реальные подборки, администратор отправляет боту **фото с подписью**:

~~~text
/addmeme meph ex YES
~~~

Пользователь должен быть указан в ADMIN_IDS, а YES означает его подтверждение, что у него **есть право распространять изображение**. Бот автоматически удаляет EXIF, конвертирует изображение в JPEG, не допускает повторов по хешу и кладёт его в assets/memes/contextual/meph/ex/. Фото появится в соответствующих сценариях без перезапуска.

**Теги вещества:** meph, alpha, stimulant, mdma, weed, alcohol, ketamine, opioid, sedative, psychedelic, general.

**Теги риска:** more, ex, contacts, money, travel, paranoia, sleep, check, general, after, ok.

Команда /addmeme (без фото) показывает пример. /meme_queue — приватная очередь внешних кандидатов; /meme_status — статус библиотеки и настроек.

Парсер meme_harvester.py периодически находит изображения на открытых ресурсах (если MEME_AUTO_DISCOVERY=1), но не публикует чужой контент без подтверждения прав. Pinterest нельзя считать бесплатным хранилищем готовых для републикации мемов: прямого несанкционированного сбора пинов нет. AI-оценка не подтверждает право собственности и не гарантирует смешность.

## Медицинская безопасность

Если тяжело дышать, сильная боль в груди, потеря сознания, судороги, опасный перегрев или тяжёлая спутанность, **не жди ответов бота и напоминаний: звони местной скорой** (112 Россия/ЕС, 911 Канада/США). При подозрении на передозировку опиоидами — налоксон, если доступен, с немедленным вызовом скорой. Не оставляй пострадавшего одного.

Карточки основаны на общих принципах снижения вреда и сигналов опасности, не содержат дозировок или советов по сочетанию веществ. Источники для проверки владельцем проекта:
- https://www.cdc.gov/stop-overdose/response/index.html
- https://www.canada.ca/en/health-canada/services/opioids/overdose.html
- https://www.cdph.ca.gov/Programs/CCDPHP/sapb/Pages/Signs-of-Overdose.aspx

**Важно:** каждый такой текст рекомендуется до публичного запуска проверить с медицинским специалистом. Бот не делает самостоятельных вызовов скорой, не измеряет состояние здоровья и не следит за человеком вне Telegram.

## Установка на VPS (без удаления данных)

**Рабочая ветка проекта:** feature/minimal-checklist-tracker. Она пока может отличаться от main. Проверь, что Git действительно установил нужную ветку. Не применяй reset --hard и не удаляй untracked-файлы.

~~~bash
set -e
cd /opt/dependence-tracker
git status --short
git fetch origin feature/minimal-checklist-tracker
git switch feature/minimal-checklist-tracker || git switch --track -c feature/minimal-checklist-tracker origin/feature/minimal-checklist-tracker
git pull --ff-only
.venv/bin/python backup_before_upgrade.py
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m compileall -q bot.py v2_experience.py v2_data.py harm_reduction.py stats_dashboard.py context_memes.py
.venv/bin/python -m unittest discover -s tests -v
sudo systemctl restart dependence-tracker
sudo systemctl is-active dependence-tracker
~~~

Команда backup_before_upgrade.py создаёт согласованную копию tracker.db через SQLite backup API и проверяет целостность. Старые резервные копии не удаляются. Все изменения схемы v2 — **добавление новых таблиц**, без удаления старых.

**Не удалять:** .env, tracker.db, data/, backups/, assets/memes/. Токены оставляются в .env, не в Git.

Если ещё нет ADMIN_IDS, внеси свой числовой Telegram ID в .env и перезапусти сервис. Настройка MEME_LEGACY_CARDS=0 рекомендована для нового оформления; MEME_AUTO_DISCOVERY=1 включает поиск внешних кандидатов. Ранее созданная опция MEME_AI_AUTOGEN требует платного API и относится к старому экспериментальному генератору карточек, а не к основному режиму v2.

## Проверка

В личном чате бота: /start → «▶️ Начать сопровождение» → выбери вещество и частоту → «🔥 Останови меня». Затем проверь «🫀 Как я?», «🆘 Мне плохо», «📊 Моя статистика». Команда /stats отправляет такой же график. /helpme сразу показывает экстренную информацию.

Код на GitHub ещё **не означает**, что система прошла проверку на твоём VPS. Сначала запусти тесты и посмотри лог systemd: sudo journalctl -u dependence-tracker -n 60 --no-pager.
