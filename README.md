# НЕ НАТВОРИ ДЕЛОВ — Telegram-бот снижения вреда

Бот помогает пользователю придерживаться собственных ограничений: чек-лист, напоминания, самочувствие, статистика, удаление данных. Не предоставляет инструкций по употреблению веществ.

## Установка
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
# Установить BOT_TOKEN в .env
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python bot.py
```

## Мемы: состояние реализации

`/meme` отправляет случайную картинку из `assets/memes/{general,ex,calls,money,travel}`. При отсутствии картинок сообщает об этом. Напоминания могут использовать локальные картинки.

`meme_collector.py scan` собирает ссылки-кандидаты; это **не изображения** и они не публикуются. `preview ID` показывает метаданные изображений страницы. `approve ID /path/image.jpg` импортирует файл после подтверждения просмотра и разрешения на распространение.

`meme_collector.py sync-licensed` — экспериментальный импорт из Wikimedia Commons с консервативной проверкой лицензии. Он может найти **0 изображений**; результат нельзя считать гарантированной коллекцией настоящих мемов. Никакой ИИ-оценки изображений, универсального обхода сайтов и автоматической публикации чужого контента пока нет.

## Проверка
```bash
.venv/bin/python -m py_compile bot.py meme_collector.py
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python meme_collector.py list
```

Тесты проверяют часть логики локально; они **не заменяют** проверку получения фото в Telegram на VPS.

## Данные и безопасность

`tracker.db` содержит личные данные. Не удаляйте `.env`, `tracker.db`, `data/` или резервные копии при очистке репозитория. Не публикуйте токен бота и приватные записи. Удаление в интерфейсе не удаляет внешние резервные копии.


## Автоматический поиск и модерация мемов

При работающем боте `MEME_AUTO_DISCOVERY=1` (по умолчанию) раз в 24 часа запускается поиск по открытым страницам. Изображения сохраняются в `data/meme_review/`, журнал — в `data/meme_review.json`. Источники могут блокировать загрузку; автоматический поиск не гарантирует пополнения коллекции.

Чтобы проверять очередь прямо в Telegram, укажите **свой числовой Telegram ID** в защищённом `.env` на сервере: `ADMIN_IDS=123456789`. Перезапустите сервис и отправьте боту `/meme_queue`. Кнопка «Проверил права и мем» подтверждает, что вы лично проверили изображение и имеете разрешение на его дальнейшее распространение; «Отклонить» исключает кандидата. Только подтверждённые изображения становятся доступны через `/meme` и напоминания. Не подтверждайте изображения, права на которые неизвестны. Система не может автоматически устанавливать авторские права по ссылке на картинку.

Для проверки без публикации: `.venv/bin/python meme_collector.py harvest`, затем `.venv/bin/python meme_harvester.py list`. Личные записи, база `tracker.db`, `.env` и резервные копии не затрагиваются.
