## 💀 Что есть в актуальной версии

| Раздел | Что делает |
|---|---|
| 💀 Сопровождение | Отметки состояния, напоминания и личные ограничения |
| ☑️ Моё слово | Свои правила против импульсивных поступков |
| 📊 Расклады Маги | Личная статистика в минималистичном формате |
| 😂 Мемчик | Фотомемы и реакции |
| 🆘 Помощь | Информация о тревожных симптомах |
| 🛠 Штаб Маги | Инструменты администратора |

**Особенности:** обычные кнопки Telegram без Mini App, короткие реплики в стиле Маги и отдельное хранение пользовательских данных в SQLite.

## 🚀 Установка актуальной версии

```bash
git clone --branch feature/maga-voice-2026 https://github.com/D00PERDAP/DEPENDENCE-TRACKER.git
cd DEPENDENCE-TRACKER
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
nano .env
chmod 600 .env
.venv/bin/python bot.py
```

В приватном файле `.env` укажи `BOT_TOKEN` от BotFather и, если нужны права администратора, свой числовой `ADMIN_IDS`. Не загружай реальные токены и базы в GitHub.

## 🔐 Важно

Бот — инструмент самонаблюдения, а **не медицинский сервис**. Не даёт гарантий безопасности и не заменяет скорую помощь. При тяжёлых симптомах немедленно обращайся в местную экстренную службу. Статистика отражает только пользовательские отметки: запуск сопровождения не означает срыв.
