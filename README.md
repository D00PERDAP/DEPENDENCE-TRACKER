# 💀 НЕ НАТВОРИ ДЕЛОВ — бот v2

Простой Telegram-помощник для взрослых, который помогает **отложить импульсивное решение**, напомнить о собственных ограничениях и быстро найти информацию при ухудшении самочувствия. Это не медицинский сервис, не трекер дозировок и не инструкция по употреблению.

## Что изменилось в v2

**В главном меню:**
- **▶️ Начать сопровождение:** 2 шага — вещество и частота. Старый чек-лист сохраняется и редактируется отдельно.
- **☑️ Я НЕ ХОЧУ:** отмечай рискованные поступки. Существующие записи сохранены.
- **🫀 Как я?:** быстрые ответы «нормально», «тревога», «тянет натворить», «не сплю», «физически плохо».
- **🔥 Останови меня:** отдельные действия при желании продолжить, звонить людям/бывшей, тратить деньги, куда-то ехать, бессоннице и паранойе. Можно включить **10-минутную проверку**, только по нажатию пользователя.
- **🆘 Мне плохо / ❓ Вопросы:** вещество → симптом → конкретная краткая карточка. При боли в груди, нарушении дыхания, судорогах, выраженном перегреве, потере сознания — сразу рекомендация вызвать местную экстренную помощь; **никаких мемов вместо срочной помощи**.
- **☀️ После сессии:** короткий опрос; по желанию можно назначить проверку состояния через 8 часов. Никакой автоматической ночной рассылки без согласия.
- **🔔 Напоминания:** каждые **10 / 15 / 30 / 60 минут** на выбор; остановка и усиление по кнопке. При включённой сессии — фотомем из интернет-шаблона со своей русской подписью и напоминанием о личных запретах.
- **📊 Статистика:** приватный JPEG-график за месяц: дни с отметками, вещества, проблемные импульсы, проверка состояния и отметки «передумал». Учитывает только самостоятельные записи, **не измеряет фактическое употребление и не ставит диагноз**.
- **🎭 Мем:** подбирается **настоящая мемная фотография**, а сверху/снизу накладывается проверенный короткий русский текст шрифтом Impact/DejaVu. Кнопка «🎯 Темы» открывает быстрый выбор контекста.

## 🎭 Фото-мемы v4 — без кривых мультиков

**Новый модуль:** `real_memes.py`. На кнопки /meme, «🎲 Ещё мем», «🎯 Темы», «🔥 Останови меня» и на плановые напоминания отправляется настоящая мемная фотография с **короткой русской подписью поверх фотографии**. Генерация старых рисунков из `meme_engine.py` осталась в кодовой базе для совместимости тестов, но **не вызывается обычными кнопками бота**.

Источники:
1. **Бесплатный Imgflip API**: `https://api.imgflip.com/get_memes` — популярные мемы, доступ без регистрации и ключа. Из списка бот выбирает подходящие проверенные по названию фотошаблоны; результат кэшируется.
2. **Твои фото с правами на использование**: администратор может отправить боту фотографию с подписью `/addmeme meph ex YES`. Бот сохраняет оригинал без EXIF и информацию об одобрении и затем автоматически использует её в подходящих ситуациях. Рекомендуются старые нелепые фотки без уже наложенного текста.
3. **Необязательный поиск Imgflip Premium**: зарегистрировать аккаунт на `https://imgflip.com/api-settings`, получить свой `IMGFLIP_API_KEY`, записать в приватный `.env` сервера и установить `MEME_PREMIUM_SEARCH=1`. До явного включения не выполняется ни одного платного поиска. По умолчанию доступны запросы «пошалим» и «русский мем», максимум **2 поиска в сутки** с суточным кэшем в SQLite. Результаты пользовательские и могут потребовать проверки авторских прав/уместности.
4. **Необязательный платный OpenAI Image API**: `OPENAI_API_KEY`, `MEME_AI_ENABLED=1`; модель `gpt-image-2.5-flare` создаёт **вымышленное фото взрослого человека в стиле плохой мыльницы 2000-х**, без текста. Русскую подпись добавляет Pillow, чтобы буквы были правильными. По умолчанию **2 запроса в сутки** (лимит `MEME_AI_DAILY_LIMIT`), только на ручные мемы; автоматические 10-минутные напоминания AI-картинки не покупают. Использование API оплачивается отдельно от ChatGPT Plus.

**Важно:** бесплатный поток Imgflip предлагает ограниченный набор популярных шаблонов; **бесконечного количества уникальных исходных фотографий он не гарантирует**. Бот старается не повторять последние 15 исходников одному пользователю и меняет короткие фразы и композицию. Для действительно новой фотографии каждый раз необходим платный генератор или пополнение своей коллекции.

Интернет-шаблоны — это пользовательский контент, права на который неодинаковы. При публичном или коммерческом распространении проверяйте разрешение владельцев фотографий и условия Imgflip. Все используемые шаблоны атрибутируются на фото. Изображение-пример из чата не добавляется в репозиторий автоматически.

**Главное меню**: одна большая кнопка «😂 ДАЙ МЕМ», рядом понятные действия «🔥 Меня несёт», «🫀 Как я?», «🔔 Напоминания», «🆘 Мне плохо», «☑️ Мои запреты» и «📊 Статистика». Вместо длинного списка на главном экране — дополнительные кнопки внутри соответствующих разделов.

Проверка на VPS: `.venv/bin/python -m unittest discover -s tests -q` и `sudo systemctl is-active dependence-tracker`. В Telegram проверь `/meme` и `/reminders`. Если сеть не даёт доступ к Imgflip, бот честно сообщает о проблеме и не подменяет фотомем случайным мультиком.


## 🔔 Точная настройка напоминаний

Старая версия могла закрывать сессию через 24 часа и переназначать таймер до подтверждения отправки. Теперь таймер действует до явного завершения либо отключения; после сбоя доставки повторяет отправку примерно через минуту.

В Telegram открой /reminders или /start → «⚙️ Напоминания». Если сессия уже запущена, нажми **«🔔 Запустить 10 минут»**: это создаст/восстановит расписание и немедленно отправит тестовый мем-фото. Следующее плановое фото должно прийти примерно через 10 минут. Если сессии нет, сперва нажми «▶️ Начать сопровождение», выбери вещество и частоту.

В настройках показывается реальный статус и количество минут до следующей отправки. «📸 Тестовый мем» отправляет картинку по запросу, не меняя расписание. При проблемах смотри системный журнал: sudo journalctl -u dependence-tracker -n 70 --no-pager.

## Медицинская безопасность

Если тяжело дышать, сильная боль в груди, потеря сознания, судороги, опасный перегрев или тяжёлая спутанность, **не жди ответов бота и напоминаний: звони местной скорой** (112 Россия/ЕС, 911 Канада/США). При подозрении на передозировку опиоидами — налоксон, если доступен, с немедленным вызовом скорой. Не оставляй пострадавшего одного.

Карточки основаны на общих принципах снижения вреда и сигналов опасности, не содержат дозировок или советов по сочетанию веществ. Источники для проверки владельцем проекта:
- https://www.cdc.gov/stop-overdose/response/index.html
- https://www.canada.ca/en/health-canada/services/opioids/overdose.html
- https://www.cdph.ca.gov/Programs/CCDPHP/sapb/Pages/Signs-of-Overdose.aspx

**Важно:** каждый такой текст рекомендуется до публичного запуска проверить с медицинским специалистом. Бот не делает самостоятельных вызовов скорой, не измеряет состояние здоровья и не следит за человеком вне Telegram.

## Установка на VPS (без удаления данных)

**Рабочая ветка проекта:** feature/minimal-checklist-tracker. Она пока может отличаться от main. Проверь, что Git действительно установил нужную ветку. Не применяй reset --hard и не удаляй untracked-файлы.

~~~bash
set -e
cd /opt/dependence-tracker
git status --short
git fetch origin feature/minimal-checklist-tracker
git switch feature/minimal-checklist-tracker || git switch --track -c feature/minimal-checklist-tracker origin/feature/minimal-checklist-tracker
git pull --ff-only
.venv/bin/python backup_before_upgrade.py
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m compileall -q bot.py v2_experience.py v2_data.py harm_reduction.py stats_dashboard.py context_memes.py photo_memes.py meme_engine.py real_memes.py
.venv/bin/python -m unittest discover -s tests -v
sudo systemctl restart dependence-tracker
sudo systemctl is-active dependence-tracker
~~~

Команда backup_before_upgrade.py создаёт согласованную копию tracker.db через SQLite backup API и проверяет целостность. Старые резервные копии не удаляются. Все изменения схемы v2 — **добавление новых таблиц**, без удаления старых.

**Не удалять:** .env, tracker.db, data/, backups/, assets/memes/. Токены оставляются в .env, не в Git.

Если ещё нет ADMIN_IDS, внеси свой числовой Telegram ID в .env и перезапусти сервис. Настройка MEME_LEGACY_CARDS=0 рекомендована для нового оформления; MEME_AUTO_DISCOVERY=1 включает поиск внешних кандидатов. Ранее созданная опция MEME_AI_AUTOGEN требует платного API и относится к старому экспериментальному генератору карточек, а не к основному режиму v2.

## Проверка

В личном чате бота: /start → «▶️ Начать сопровождение» → выбери вещество и частоту → «🔥 Останови меня». Затем проверь «🫀 Как я?», «🆘 Мне плохо», «📊 Моя статистика». Команда /stats отправляет такой же график. /helpme сразу показывает экстренную информацию.

Код на GitHub ещё **не означает**, что система прошла проверку на твоём VPS. Сначала запусти тесты и посмотри лог systemd: sudo journalctl -u dependence-tracker -n 60 --no-pager.
