# НЕ НАТВОРИ ДЕЛОВ 💀

Русскоязычный Telegram-бот: личный чек-лист, напоминания, самочувствие, статистика и мемы с чёрным юмором. Не даёт инструкций по употреблению веществ, не заменяет медицинскую помощь.

## Мемы: три независимых режима

### 1. Бесплатная автоматическая библиотека — работает сразу

Модуль **meme_studio.py** содержит **98 оригинальных русскоязычных шуток**, придуманных специально для бота: меф, Паша Техник (без фальшивых цитат), вещества, паранойя, чёрная ирония, ночные звонки, деньги, бывшие, необдуманные поездки. Pillow рисует шесть вариантов квадратных мем-карточек с крупным кириллическим текстом.

При запуске бот создаёт первые 16 изображений, а остальные дорисовывает в фоне. Существующие изображения не перезаписываются. Для публикации собственных мемов **не нужны ручное подтверждение, интернет или API-ключ**.

- **/meme** — прислать мем.
- **🎲 Ещё мем** — следующий.
- **😂 Зашло / 🥱 Не смешно** — оценить качество.
- Бот помнит **25 последних показов каждому человеку** и старается не повторять их; мемы с 4+ оценками, 75% которых отрицательные, исключаются из подборки.
- Напоминания получают тематические картинки, оценки и тот же анти-повтор.
- Удаление пользовательских данных очищает также их историю мемов и оценки.

**Ограничение:** 98 шуток — конечная коллекция, не бесконечная нейросеть. Реакции не гарантируют объективно смешной результат.

### 2. Неограничиваемая исходным каталогом генерация новых авторских шуток — необязательно

**meme_ai.py** может раз примерно в сутки генерировать оригинальные шутки и подвергать их второму редакторскому запросу. Затем локально проверяет повторяемость и нежелательные сюжеты, рисует собственные мемы и добавляет их в общую библиотеку.

**По умолчанию выключено**: OpenAI API оплачивается отдельно от подписки ChatGPT Plus. Для включения добавьте в секретный .env:

~~~dotenv
MEME_AI_AUTOGEN=1
OPENAI_API_KEY=your_separately_billed_api_key
MEME_AI_MODEL=gpt-4o-mini
~~~

Перезапустите сервис. Нейросеть может ошибаться в юморе: кнопки оценок постепенно подавляют неудачные шутки. В API передаются только общие запросы на шутки, а не личные чек-листы, истории или Telegram ID. Перед включением проверьте свой бюджет API.

### 3. Сайты и публичные сообщества — поиск и модерация чужих изображений

**meme_collector.py scan** находит тематические страницы, а **meme_harvester.py** собирает ограниченные изображения в папку data/meme_review/, фильтрует формат, размеры, похожесть, подписи и темы. Сборщик ограничивает HTTPS, блокирует локальные сети и проверяет переадресации; очередь сохраняется атомарно, с блокировкой от конфликтующих записей.

При MEME_AUTO_DISCOVERY=1 он обновляет кандидатов примерно раз в сутки. Сайты могут блокировать запросы. Совпадение картинки со словами «меф» или «Паша Техник» не даёт права её перепубликовать.

Для просмотра присылайте **/meme_queue** со своего Telegram-аккаунта. В .env должен быть ваш числовой Telegram ID:

~~~dotenv
ADMIN_IDS=123456789
~~~

Публикуйте чужие картинки только после проверки содержания и права на распространение; при сомнениях нажимайте «Не подходит». Одобренные материалы автоматически становятся доступны в /meme и напоминаниях.

### Опциональная визуальная проверка чужих мемов

Если уже есть отдельно оплачиваемый OPENAI_API_KEY, можно включить **MEME_AI_VISION=1** в .env: при каждом автоматическом поиске не более **6 миниатюр** отправляются в модель для оценки темы, читаемости и юмора (0–5). Слабые картинки сохраняются с пометкой «отклонено» и не публикуются. Проверка не выявляет правообладателя и **никогда не отменяет обязательной проверки прав** перед републикацией. AI-модель может ошибаться; по умолчанию режим выключен. Обработка изображений через API платная.

Админская команда **/meme_status** показывает, сколько своих и одобренных чужих мемов есть в библиотеке, очередь проверки, оценки и включённые режимы.

**Pinterest:** в коде есть каталог тематических поисковых запросов для возможной авторизованной интеграции, но прямого автоматического скачивания чужих пинов, обхода защиты и автопубликации без разрешения нет.

## Установка / обновление

~~~bash
cd /opt/dependence-tracker
git pull --ff-only
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m compileall -q bot.py meme_studio.py meme_ai.py meme_vision.py meme_review_store.py meme_harvester.py meme_collector.py
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python meme_studio.py count
sudo systemctl restart dependence-tracker
sudo systemctl is-active dependence-tracker
~~~

Если нет кириллических шрифтов: sudo apt-get install -y fonts-dejavu-core.

Для проверки без публикации: **.venv/bin/python meme_studio.py** создаёт оригинальные картинки; **.venv/bin/python meme_collector.py harvest** ищет внешних кандидатов; **.venv/bin/python meme_harvester.py list** показывает очередь.

В GitHub Actions добавлены тесты для Python 3.12 и создание 16 пробных картинок. Это не заменяет проверку доставки фото в Telegram на VPS.

## Данные и безопасность

Сохраняйте **.env** (токены), **tracker.db** (личные записи), **data/** (кандидаты и история генерации), **assets/memes/** (одобренные изображения). Ничего из этого не удаляйте при обновлении. Git игнорирует только пересоздаваемые файлы original_*.jpg, но не вручную одобренные картинки. Резервные копии удаляются отдельно.

## Команды

**/start** — главное меню. **/meme** — мем. **/meme_queue** — приватная очередь администратора.
