# НЕ СЕГОДНЯ — Telegram-трекер

Без Mini App. Личный журнал употребления, цели снижения вреда, записи о самочувствии, отдельные счётчики перерывов, мемные подписи и удаление всех данных.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Впишите BOT_TOKEN в .env
python bot.py
```

Данные хранятся локально в SQLite (`tracker.db`). Обеспечьте защиту сервера, резервных копий и `.env`; не публикуйте базу. При удалении из бота удаляются записи из активной базы, но не внешние резервные копии. Бот не предоставляет дозировок или гарантий безопасности.
