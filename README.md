## 🧭 Единое сообщение (режим Маги)

Навигация в личном чате строится вокруг **одного активного экрана**. Новый модуль `ui_manager.py` хранит идентификатор сообщения в локальной базе `data/ui_screens.sqlite3` (она исключена из Git) и использует редактирование Telegram-сообщений:

- Кнопки обычных текстовых разделов редактируют существующее сообщение.
- Статистика и ручные фотомемы заменяют фотографию внутри активного экрана.
- Telegram не позволяет превратить обычный текст в фото без отправки нового сообщения. В таком случае бот отправляет замену, запоминает её ID и старается удалить прежний экран.
- Если сообщение было удалено пользователем, создаётся новое активное.
- Переходы одного пользователя сериализуются внутри процесса. **Запускать одновременно два polling-процесса с одним токеном нельзя.**
- Фоновые напоминания, экстренные уведомления, ввод текста и отдельная секретная гавань не входят в единое сообщение: они могут требовать отдельных отправок.

Это **best-effort** режим, а не обещание технически невозможного абсолютного «одного сообщения» при любых действиях.

Проверка навигации: `.venv/bin/python -m unittest tests.test_ui_manager -v`. Полная проверка: `.venv/bin/python -m unittest discover -s tests -v`.

## 🚀 Быстрый старт

**Требования:** Python 3.12+, Telegram Bot Token, доступ в интернет. Для расширенной обработки видео и кадров может понадобиться `ffmpeg`.

```bash
git clone --branch feature/maga-voice-2026 https://github.com/D00PERDAP/DEPENDENCE-TRACKER.git
cd DEPENDENCE-TRACKER

python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt

cp .env.example .env
nano .env
chmod 600 .env

.venv/bin/python bot.py
```

В `.env` укажи токен своего бота:

```dotenv
BOT_TOKEN=your_telegram_bot_token
ADMIN_IDS=your_numeric_telegram_id
```

Остальные параметры уже описаны в [`.env.example`](.env.example). Платные AI-возможности **необязательны** и по умолчанию отключены. Подписка ChatGPT Plus не включает оплату OpenAI API.

## 🖥 Обновление на VPS

Если проект уже установлен в `/opt/dependence-tracker` и использует ветку Маги:

```bash
cd /opt/dependence-tracker
git status -sb
git pull --ff-only origin feature/maga-voice-2026
.venv/bin/python -m compileall -q bot.py v2_experience.py v2_data.py stats_dashboard.py admin_center.py
sudo systemctl restart dependence-tracker
sudo systemctl is-active dependence-tracker
```

**Важно:** перед `git pull` проверь локальные изменения. Если Git предупреждает о конфликте, сначала сохрани изменённые файлы; не используй `git reset --hard` или `git clean -fdx` для исправления наугад.

Проверка журнала сервиса:

```bash
sudo journalctl -u dependence-tracker -n 60 --no-pager
```

## 🔐 Приватность и безопасность

- Данные хранятся в локальных SQLite-базах на сервере. Это **не** сквозное шифрование.
- `.env`, `tracker.db`, `data/` и резервные копии нельзя публиковать в GitHub.
- Удаление записей через бота не удаляет автоматически копии на других носителях и в резервных архивах.
- Статистика показывает **самостоятельно внесённые записи**. Запуск сопровождения **не равен срыву**, а график не является медицинским заключением.
- Для собственной медиатеки загружай только материалы, на использование которых есть права.

### 🆘 Важное предупреждение

Бот **не является врачом, скорой помощью или гарантией безопасности**. Он не определяет дозы, не диагностирует состояния и не вызывает экстренные службы автоматически.

При затруднённом дыхании, сильной боли в груди, судорогах, потере сознания, опасном перегреве или тяжёлой спутанности **немедленно обращайся в местную экстренную службу**. Не жди напоминаний или ответа бота.
