# НЕ НАТВОРИ ДЕЛОВ — новая версия

Telegram-бот для добровольного журнала употребления и снижения вреда. Не медицинское устройство и не сервис расчёта безопасных доз.

## Главная
- 📝 Записать: выбрать вещество и сохранить событие, закрыть запись при необходимости.
- 🫀 Как я?: отметить самочувствие и быстро открыть экстренную информацию.
- 🎲 Мем: готовые изображения из assets/meme_pack или динамические карточки.
- ⚙️ Ещё: история, уведомления, помощь, удаление данных.

## Уведомления
Отключены по умолчанию. После явного согласия и новой записи создаются четыре проверки состояния (через 30, 90, 240, 720 минут). Фоновый asyncio-процесс проверяет очередь каждые 30 секунд. Уведомления не сигнализируют об окончании действия вещества и не рекомендуют повторное употребление. Можно выключить в любой момент.

## База
При старте создаются новые таблицы companion, checks, moods. Старые users, sessions, entries, goals не удаляются. До обновления сделайте резервную копию tracker.db.

## Мемы
Готовые картинки размещать в assets/meme_pack/*.jpg (или PNG/WebP). Если папка пуста, используется meme_cards.py. Для лицензионных фотографий сохранять источник и авторство.

## Деплой
1. Проверить синтаксис: .venv/bin/python -m py_compile bot.py meme_cards.py
2. Сделать копию БД: cp tracker.db tracker.db.backup
3. Обновить зависимости: .venv/bin/pip install -r requirements.txt
4. Перезапустить только dependence-tracker.service.
5. Проверить journalctl -u dependence-tracker -n 50 --no-pager

Не запускать одновременно две копии polling-бота с одним токеном.
