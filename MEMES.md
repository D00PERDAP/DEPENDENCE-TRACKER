# Мемы для бота

Вместо генерации — реальные картинки. Скрипт `meme_collector.py` ищет кандидатов через Wikimedia Commons API и сохраняет ссылки с лицензиями в `data/meme_candidates.json`.

**Важно:** скрипт не публикует найденное автоматически. Большинство результатов поиска не будут достаточно смешными или подходящими. Редактор должен открыть страницу, посмотреть картинку, проверить лицензию и только потом подтвердить.

## Использование на VPS

```bash
cd /opt/dependence-tracker
.venv/bin/python meme_collector.py scan
.venv/bin/python meme_collector.py list
.venv/bin/python meme_collector.py approve 3
```

При подтверждении введите `YES`. Файл будет скачан в `assets/memes/<category>/` и автоматически станет доступен боту без перезапуска. Для отклонения: `python3 meme_collector.py reject 3`.

Категории: `ex` (бывшая), `calls` (звонки), `money` (траты), `travel` (поездки), `general` (наркотический чёрный юмор).

Чтобы обновлять список кандидатов ежедневно, добавьте cron-задание (после проверки скрипта):

```cron
20 4 * * * cd /opt/dependence-tracker && /opt/dependence-tracker/.venv/bin/python meme_collector.py scan >> /opt/dependence-tracker/meme_scan.log 2>&1
```

**Ежедневно обновляется только очередь кандидатов, а не публичная подборка.** Новые картинки попадают к пользователям лишь после одобрения. Пользовательские данные никуда не передаются.

Реальные русские треш-мемы часто не имеют открытой лицензии. Для таких источников необходимо отдельное разрешение правообладателя; не обходите ограничения сайтов и не скачивайте чужие изображения массово без разрешения.

Бот читает локальные файлы и, если подходящих мемов нет, присылает текст. Старые данные SQLite сохраняются.
