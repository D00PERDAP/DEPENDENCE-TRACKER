# Голос Маги: бесплатная локальная альтернатива

В админке «🎙 Голос Маги» → «🎭 Выбрать голос»:

- **Дмитрий (Edge)** — прежний голос, работает онлайн и не требует новых пакетов.
- **Гамат (Silero)** — русскоязычный голос \`ru_gamat\` модели \`v5_cis_base\`.
- **Эдуард (Silero)** — русскоязычный голос \`ru_eduard\` той же модели.

Оба варианта Silero — экспериментальные: происхождение диктора не является
гарантией определённого акцента. На слух можно сравнить через предпросмотр.
Для действительной имитации индивидуальной манеры речи потребуется голосовая
модель или образец голоса с правом его использования.

## Установка на VPS (необязательно)

Не устанавливайте новые пакеты без необходимости: PyTorch может занять
сотни мегабайт диска и заметное количество ОЗУ. Сначала убедитесь, что VPS
располагает ресурсами. При нехватке памяти оставьте Edge.

После обновления репозитория и прохождения штатных тестов:

\`\`\`bash
cd /opt/dependence-tracker
sudo apt-get update
sudo apt-get install -y ffmpeg git
.venv/bin/pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.venv/bin/pip install omegaconf
sudo systemctl restart dependence-tracker
\`\`\`

Первый запуск Silero загрузит модель и исходный код с GitHub в кеш PyTorch.
Далее синтез производится **на VPS**, без платного TTS API. Это бесплатная
по лицензии MIT модель, но оплаченные вами серверные ресурсы остаются.
Для корректной обработки русского текста возможно потребуется расстановка
ударений; модель CIS base не обеспечивает её автоматически.

Если Silero не запустится, бот сообщит причину при предпросмотре.
Верните «Дмитрий (Edge)» в меню выбора голоса. Самостоятельно
переключать выбранный голос при ошибке не требуется.
