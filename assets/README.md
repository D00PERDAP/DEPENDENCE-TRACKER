# Мемные шаблоны

Для фоновой картинки с Путиным положите в эту папку файл `putin.jpg` (изображение, на использование которого у вас есть права). Без него генератор создаёт тёмную карточку с текстом.

Картинки генерируются локально через Pillow: без API, платежей и интернета. На Ubuntu установите `fonts-dejavu-core`.

Никакие изображения и записи пользователей не загружаются во внешние сервисы генерации.
